# D' Cozy Brew Café — Company Profile Website

## 📌 Project Overview
This is a multi-page company profile website for **D' Cozy Brew Café**, a cozy café located in Pila, Laguna. Built using **Laravel 12** and **Tailwind CSS**, this project demonstrates proper MVC architecture, Laravel Routing, and Blade templating.

## 📄 Pages Included
- **Home** — Hero section, introduction, featured products
- **About** — Company history, mission, vision, core values, team
- **Products** — 6 menu items with icons, descriptions, and prices
- **Contact** — Contact information, social media links, and message form

## 🛠️ Technologies Used
- **Laravel 12** — PHP Framework
- **Blade Templates** — Laravel templating engine
- **Tailwind CSS** — Styling & Responsive Design
- **Font Awesome** — Icons
- **PHP 8.2**

## 📂 Project Structure
resources/views/pages/
├── home.blade.php
├── about.blade.php
├── products.blade.php
└── contact.blade.php
routes/web.php

## 🚀 How to Run
1. Open terminal in project folder
2. Run: `composer install`
3. Run: `php artisan serve`
4. Open browser: `http://127.0.0.1:8000`

## ✨ Features
- Responsive design — works on phone, tablet, and desktop
- Consistent navigation & footer across all pages
- Coffee-themed color palette (Brown & Cream)
- Clean, organized Laravel routing structure
- 4 complete functional pages
